# cpp02

## Overview

This project continued building my understanding of C++ by introducing more advanced object-oriented concepts. It focused on how classes can behave more naturally through operator overloading and how data can be represented in a more precise way using fixed-point numbers.

## What I Learned

### Orthodox Canonical Form

One of the main ideas introduced in this module was the Orthodox Canonical Form (OCF).

I learned that a well-formed class in C++ should typically include:

```
default constructor
copy constructor
copy assignment operator
destructor
```

This helped me understand how objects are created, copied, assigned, and destroyed, and why controlling these operations is important for managing resources properly.

### Operator Overloading

This module also introduced operator overloading, which allows custom types to behave more like built-in types.

I learned how to:

```
define behavior for operators like +, -, *, =, <<
make classes easier and more intuitive to use
```


This made my classes more expressive and improved code readability.

### Fixed-Point Numbers

Another key concept was the implementation of fixed-point numbers.

I learned how to:

```
represent fractional numbers using integers
control precision manually
convert between float, int, and fixed-point formats
```


This helped me better understand how numbers can be represented at a lower level without relying on floating-point hardware.


## Final Thoughts

CPP02 builds on the foundations of C++ by introducing cleaner class design and more expressive code patterns. It strengthened my understanding of how to design classes that behave naturally and how data representation can be controlled more precisely.
