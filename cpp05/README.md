# cpp05

## Overview

This project introduced the concept of exception handling in C++, along with deeper reinforcement of class design and robustness. It focused on building safer programs by properly managing errors and defining clear rules for failure cases.

## What I Learned

### Exceptions

One of the main concepts in this module was exception handling.

I learned how to:

```
throw exceptions when an error occurs
use try and catch blocks to handle errors safely
separate normal logic from error-handling logic
```


This made my programs more reliable and easier to debug.

### Standard Exceptions

This module also introduced standard exceptions provided by the C++ library.

I learned how to:

```
use exceptions like std::exception
understand and extend exception classes
create meaningful error messages using what()
```


This helped me standardize how errors are reported in my code.

### Custom Exceptions

Another important concept was creating custom exceptions.

I learned how to:

```
define my own exception classes
override the what() function
use exceptions to represent domain-specific errors
```


This allowed me to make error handling more precise and meaningful.

### Class Design with Exceptions

This module also reinforced how exceptions integrate with object-oriented design.

I learned how to:

```
ensure class methods remain safe and predictable
use exceptions to enforce constraints in constructors and methods
handle invalid states properly
```


This improved the overall robustness of my class implementations.

## Final Thoughts

CPP05 builds on previous modules by introducing structured error handling in C++. It helped me understand how to write safer and more reliable programs by properly managing exceptional cases and enforcing rules within class design.
