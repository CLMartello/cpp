# cpp04

## Overview

This project introduced deeper concepts of object-oriented programming in C++, focusing on polymorphism, abstract classes, and interfaces. It helped me understand how to design flexible systems where behavior can be defined at runtime through inheritance and virtual functions.

## What I Learned

### Polymorphism

One of the main concepts in this module was polymorphism.

I learned how to:

```
use a base class pointer or reference to handle derived class objects
enable runtime method selection using virtual functions
write more flexible and reusable code structures
```


This made it possible to treat different derived classes in a unified way while still preserving their specific behavior.

### Virtual Functions

This module introduced virtual functions as a key tool for polymorphism.

I learned how to:

```
declare functions in a base class that can be overridden in derived classes
use the virtual keyword to enable dynamic dispatch
ensure the correct function is called at runtime
```


This helped me understand how C++ decides which function implementation to execute.

### Abstract Classes

Another important concept was abstract classes.

I learned how to:

```
define pure virtual functions using = 0
prevent direct instantiation of base classes
force derived classes to implement specific behaviors
```


This improved my ability to design clear and structured interfaces.

### Interfaces

I also learned how abstract classes can be used as interfaces in C++.

I learned that:

```
interfaces define what a class must do, not how it does it
they help enforce consistent behavior across multiple classes
they improve code organization and scalability
```


## Final Thoughts

CPP04 builds on previous modules by introducing polymorphism and abstract design. It strengthened my understanding of how to structure programs using interfaces and dynamic behavior, making code more flexible and maintainable.
