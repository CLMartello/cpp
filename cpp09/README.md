# cpp09

## Overview

This project focused on more advanced usage of the C++ Standard Template Library (STL), building on the concepts introduced in previous modules. It introduced different containers and helped me understand how to choose the right data structure depending on the problem.

## What I Learned

### STL Containers

One of the main concepts in this module was working with different STL containers.

I learned how to use:

```text
std::vector
std::deque
std::stack
std::map
```

Each container has different characteristics and is useful for different situations.

### Container Adaptors

This module also introduced container adaptors.

I learned how:

```text
std::stack can provide stack-based access to another container
different underlying containers can be used depending on requirements
container adaptors provide a restricted interface
```

This helped me understand how existing containers can be adapted to provide specific behaviors.

### Bitcoin Exchange

One of the exercises involved creating a program to calculate Bitcoin exchange values using historical price data.

I learned how to:

```text
read and parse input files
work with dates and numerical values
search for corresponding exchange rates
validate input data
handle invalid or missing data
```

This helped me combine file handling, containers, parsing, and error handling into a single program.

### Reverse Polish Notation

Another exercise focused on evaluating mathematical expressions written in Reverse Polish Notation (RPN).

I learned how to:

```text
parse expressions
use a stack to store intermediate values
apply mathematical operators
validate expressions and detect errors
```

This gave me practical experience with stacks and showed how a simple data structure can be used to solve a more complex problem.

### Merge-Insert Sort

The final exercise introduced the Ford-Johnson merge-insert sorting algorithm.

I learned how to:

```text
organize data into pairs
compare and sort elements efficiently
use recursion as part of the sorting process
work with different STL containers
compare performance between containers
```

This helped me better understand algorithmic complexity and the performance differences between data structures.

## Final Thoughts

CPP09 builds on the STL concepts from previous modules by applying containers and algorithms to more complex problems. It strengthened my understanding of data structures, parsing, sorting, and algorithmic efficiency while giving me more practical experience with the C++ Standard Library.
