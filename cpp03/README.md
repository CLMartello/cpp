# cpp03

## Overview

This project introduced the fundamentals of object-oriented programming in C++ through inheritance. It helped me understand how classes can be extended and how shared behavior can be reused and specialized in a clean and structured way.

## What I Learned

### Inheritance

One of the main concepts in this module was inheritance.

I learned how to:

```
create a base class and derive new classes from it
reuse attributes and methods from an existing class
extend or override functionality in child classes
```


This made it possible to design cleaner and more modular class hierarchies.

### Access Specifiers in Inheritance

This module also reinforced the importance of access control when working with inheritance.

I learned the difference between:

```
public inheritance
protected inheritance
private inheritance
```


and how they affect what members of the base class can be accessed in derived classes.

### Constructors and Destructors in Inheritance

I learned how object creation and destruction works in an inheritance chain.

In particular:

```
base class constructor is called first
derived class constructor is called after
destructors are called in reverse order
```


This helped me understand the lifecycle of objects in more complex class structures.

### Method Overriding

Another important concept was method overriding.

I learned how to:

```
redefine a base class method in a derived class
use virtual functions to enable runtime behavior changes
```


This introduced the foundation of polymorphism in C++.

## Final Thoughts

CPP03 builds on previous modules by introducing inheritance and class hierarchies. It helped me understand how to structure code in a more scalable way and laid the groundwork for more advanced polymorphism concepts in future projects.
